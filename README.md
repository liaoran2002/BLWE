# BLWE

**把 某 站的收藏夹 / 合集 / 系列直接铺到桌面，当一块会播的壁纸。**

粘一个链接就是一个播放列表，点哪一条就放哪一条，整个嵌进桌面壁纸层循环播。
也能导入音乐歌单，逐首去 某 站找最像原曲的视频，两条进料通道共用同一个播放引擎。

> **BLWE** = **B**i**L**i**W**allpaper**E**ngine

## 功能特性

### 📺 视频列表：收藏夹 / 合集直接当播放列表

- **一个「新建列表」收口所有来源**：粘收藏夹 / 合集 / 系列的链接，或登录后从「收藏夹」「订阅合集」里挑一个
  （两者都是**封面网格**，点一下就选中，不用在下拉里逐行读名字）。什么都不选就是空列表，自己往里加。
- **拖进窗口就播**：单条视频、合集、收藏夹、音乐歌单、本地视频文件，拖到窗口任意位置松手即导入并开始播放。
  重复拖同一个只会重新同步，不会攒出一堆重复列表。
- **记住播到第几条**：关掉重开还在原处。重新同步后按 bvid 重新定位，你新收藏一条也不会错位。
- **列表管理**：同步（提示 `+N / -M` 告诉你变了多少）、添加视频、爱心收藏置顶、重命名、删除
  （只删本地列表，不动你 某 站上的收藏夹）。
- **本地视频也能进来**：和 某 站视频完全同等待遇。文件被移动或删除时那一条会标「文件丢失」，
  点「定位」重选文件即可，列表位置、收藏、播放进度都保留。

### 🎵 歌单：从音乐平台到 某 站视频

- **粘歌单链接即可导入**，自动解析曲目（歌名 / 歌手 / 专辑 / 封面 / 时长）；
  不粘链接也行，直接在文本框里按行填「歌名-歌手」。
- **多歌单管理**：想建几个都行，各自记住播放到第几首，支持手动 / 启动时 / 定时同步。
- **智能匹配**：先硬过滤（标题里歌名是否独立出现、时长是否接近、是否命中过滤词），再打分排序
  （歌手名命中 +100，关键词加减分，简繁自动归一；结果不够时自动换搜索词再搜）。
  你手动换过的视频会被记住，下次续播精确回到同一个。
- **规则可调**：过滤关键词、关键词加权、时长容差、降级阈值都在「设置 → 搜索」里。

### ▶️ 播放

- **能拿多高就多高**：1080P60 / 4K / 8K，Hi-Res / 杜比全景声；拿不到高清时自动退回 720P。
- **切歌几乎无感**：播放时提前把前后两首准备好，通常 0.3~0.9 秒就出画。
- **清晰度 / 音质随手切**：点标题旁的角标，列表里是当前视频真正能选的档位；只作用于这一条，下一首回到设置上限。
- **卡顿自动恢复**：换线路 → 降清晰度（默认关，可开）→ 降到 720P → 提示检查网络。
- 播放模式（列表循环 / 单曲循环 / 随机）、进度记忆、失效视频自动跳过。

### 🖥 桌面与系统

- **桌面壁纸模式**：一键嵌进 Windows 桌面壁纸层，铺满桌面且不进任务栏，
  此时标题栏与控制栏隐藏，操作走托盘；退出时按进入前的窗口状态还原。
- **系统媒体控件（SMTC）**：歌名 / 歌手 / 封面同步到系统媒体浮层与锁屏，媒体键直接可控。
- **托盘**：右键是个迷你控制台 —— 当前歌曲、可拖动的进度条、音量 / 上一首 / 播放暂停 / 下一首 / 模式切换，
  下面是各管理入口与退出。
- **定时暂停 / 定时关闭**：可叠加「暂停时冻结倒计时」「等视频播完再停」「停止后退出程序」。
- **其他**：界面锁定（`S`）、全屏自动锁定、任务栏播放进度、输出设备变化自动暂停、
  开机自启、关闭到托盘、某 站账号登录（登录后可用更高清晰度与音质）。

### 🎨 界面

- **无边框 + 毛玻璃**，主题色、字体颜色、透明度、模糊强度、阴影强度都能调，深浅自动按底色适配。
- **窗口宽高比**可选 16:9 / 4:3 / 不限制，也能直接输入任意比例（含 21:9、9:16 竖屏）。
- **快捷键**：`空格` 播放暂停 · `↑ ↓` 音量 · `← →` 快进退 5 秒 · `F` 全屏 · `Esc` 退出全屏 · `S` 锁定 / 解锁。

## 快速开始

```bash
# 安装依赖（建议 Node 20+）
npm install

# 开发模式（渲染进程 HMR + Electron）
npm run dev

# 壁纸模式开发（启动后直接嵌入桌面）
npm run dev:wall

# 类型检查（主进程 + 渲染进程）
npm run typecheck

# 构建到 out/（明文，调试用）
npm run build

# 打包：免安装目录 / 安装包（会自动做代码保护，产物在 release/）
npm run pack
npm run dist
```

> 开发模式不触发代码保护。`pack` / `dist` 会**就地改写 `out/`**，跑完想继续调试请先 `npm run build:only` 还原明文。
>
> 若终端里有 `ELECTRON_RUN_AS_NODE=1`（某些 CI 环境会设），`electron` 会退化成纯 Node 而报奇怪的错，跑之前清掉它。

## 使用说明

1. **最省事的开始：把东西拖进窗口**。单条视频 → 进「默认列表」立刻播；合集 / 系列 / 收藏夹 → 导入成视频列表；
   音乐歌单链接 → 切到音乐模式并播第一首；本地视频文件 → 同样进「默认列表」立刻播。
   想手动管理就点左上角名字 →「视频管理」→「新建列表」。
2. **加视频 / 收藏**：视频管理里选中列表 →「添加视频」；列表里点爱心就是收藏。收藏和手动添加的条目都会置顶，重新同步不会丢。
3. **添加音乐歌单**：视频管理左下角「← 歌单管理」→ 新建歌单 → 粘分享链接，或按行填「歌名-歌手」。
4. **开始播放**：在列表里点任意一条。两个工作区（视频 / 音乐）共用同一个播放引擎，切模式不会打断正在播的内容。
5. **切清晰度 / 音质**：点标题右侧的角标。设置里的「最高清晰度 / 最高音质」是自动播放时的上限。
6. **同步**：列表弹窗左上角的刷新按钮，或在管理器里点某个列表的「同步」。本地列表没有远端来源，会自动跳过。
7. **登录 某 站**：点右上角头像扫码登录，登录后自动使用更高清晰度与音质。
8. **壁纸模式 / 定时 / 外观**：分别在各面板与「设置」里，改完立刻生效并保存。

## 配置文件位置

数据默认都在 `%APPDATA%/BiLiWallpaperEngine/`：

| 内容 | 文件 |
| :--- | :--- |
| **列表、曲目、候选视频、收藏、播放位置** | **`blwe.db`**（SQLite 单库） |
| 应用配置（清晰度上限、界面颜色、续播开关……） | `setting.json` |
| 播放地址缓存 | 在 `blwe.db` 里（默认 3 天过期，过期只清地址、不删收藏；**0 = 永久**） |

**免安装（便携）版**按下面的优先级选数据目录：

| 情况 | 用哪个目录 |
| :--- | :--- |
| `%APPDATA%/BiLiWallpaperEngine` 里**已经有数据** | 就用它（安装版 / 便携版共用一份，换版本不会「数据不见了」） |
| 没有数据，且当前是便携版 | exe 同级的 **`blwedata/`**（自动创建，数据跟着程序走） |
| 没有数据，且是安装版（全新环境） | 默认的 `%APPDATA%/BiLiWallpaperEngine` |

> 目录名用 `blwedata` 而不是通用的 `data`，避免和丢在同一个文件夹里的别的软件撞名。
> 判断「有没有数据」会看 `blwe.db`，所以只带一个库文件也能被识别成便携数据目录。

## 常见问题

**Q：清晰度只有 720P / 登录了还是没变？**

```
高清能不能拿到取决于两件事：① 这个视频本身有没有高清版本（老视频、转载常常只有 720P）；
② 你的账号权限够不够（没登录 / 没大会员时平台不会给高清地址）。

登录后会自动重新取一次播放地址，不用重启。如果当前这条还是旧档位，
点一下清晰度角标手动选一次即可。
```

**Q：控制栏里调成 360P，为什么下一首又变回 1080P？**

```
这是故意的：角标里的选择只作用于**当前这一条**（临时试试 / 这条只有这个档位），
下一首回到设置里的默认上限。想永久改就去「设置 → 播放 → 最高视频清晰度」。
```

**Q：进了壁纸模式怎么回窗口？点了没反应怎么办？**

```
壁纸模式下任务栏没有按钮，操作都在托盘上：左键单击托盘图标直接回窗口模式，
右键菜单里点「窗口模式」也一样。这两条路会直接问系统「窗口是不是还挂在桌面壁纸层」，所以状态异常也能回来。

如果点「壁纸模式」提示不可用，通常是：
- 不在 Windows 上；
- 资源管理器（explorer.exe）没在运行，或桌面被第三方动态壁纸软件接管（两者互斥）；
- 原生模块没装上，重新 npm install 即可。
```

**Q：提示「切歌太快了」/「未登录」/「搜索失败」？**

```
「切歌太快了」= 切得太频繁，平台暂时不回应搜索了，等一两分钟就好（不会封号）。
   别连续狂点上一首 / 下一首；加载中时这几个按钮本来就会暂时点不动，就是为了防连点。

「未登录」= 点右上角头像登录。没登录时平台只放出一部分搜索结果，很多歌搜不到。
「搜索失败」= 检查本机网络 / 代理 / VPN。网络抖动导致的失败不会被记成「这首没有」。
```

**Q：提示「结果都被过滤掉了」，或者视频列表里少了几个？**

```
这是过滤规则在起作用（不是搜索失败）：① 标题里歌名不是独立出现；② 时长和歌单里那首歌差太多；
③ 标题命中「过滤关键词」（默认是一组谱类词：吉他谱、钢琴谱、指弹……）。

嫌砍太多就去「设置 → 搜索」把时长容差调大、或删掉几个过滤关键词；嫌不够严就反过来。
改完规则后已经搜过的歌不会自动更新，点列表左上角的刷新重新搜一次。

你自己收藏或手动添加的视频不受过滤影响，会一直留在列表最前面。
```

**Q：收藏会丢吗？删缓存会怎样？**

```
不会。收藏没有过期时间，「搜索结果过期时间」只清理播放地址，不动收藏。
删缓存只会让下一次搜索重新联网（慢一点点），列表、配置、续播记录都不受影响。
只有你主动点设置里的「全部清除」才会把收藏一起清掉。
```

**Q：定时到点了为什么没有立刻停？**

```
看你有没有勾「视频播放完毕后停止播放」。勾了的话，倒计时归零只是进入等待状态
（按钮显示红色 00:00），要等某条视频播到开头才真的停，这样不会把你正听的从中间掐断。
不勾就是归零那一刻立刻停。要连程序一起退，还需要勾「停止播放后关闭程序」。
```

**Q：卡顿时为什么先换线路，而不是直接降清晰度？**

```
同一个清晰度平台通常给了好几条线路。某条卡住时换一条往往立刻就好，画面还是原清晰度、不损失观感；
线路都试完还不行，才考虑降清晰度。（那一步默认还要你自己确认，可在设置里打开自动降。）
```

## 打包与代码保护

`npm run pack` / `npm run dist` 会对主进程做字节码编译、渲染层做混淆与加密，
避免打包产物被直接读源码或改一行就重新分发；`npm run dev` 不受影响。

需要说明的是：密钥必须随客户端一起分发，所以这层保护只是**提高门槛**，不构成「绝对安全」。
实现细节见 [ARCHITECTURE.md](ARCHITECTURE.md)。
